What is happening under the hood?

A FIFO queue explores neighbours in layers. Every edge has equal weight, so the first route to the goal is a shortest route. BFS time and space: O(V + E) and O(V). A* prioritizes distance travelled plus Manhattan distance to the goal. This demo uses a simple sorted frontier, rather than a heap. Both use the same walls and four-directional movement. This is a standalone interactive demo, not a hosted project backend.
